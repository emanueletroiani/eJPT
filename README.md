Vista la popolarità di Windows, la maggior delle vulnerabilità sono state pubblicate, rendendole relativamente semplici da sfruttare.

Indipendentemente dalle varie versioni e release, tutti i sistemi operativi Windows hanno in comune:

- I sistemi operativi Windows sono stati **sviluppati** con il **linguaggio** di programmazione **C**, il che rende **vulnerabili** a **buffer overflow**, **esecuzione** di **codice arbitrario**, ecc.
- Per **impostazione predefinita**, **Windows non è configurato** per funzionare **in modo sicuro** e richiede un'implementazione proattiva delle pratiche di sicurezza per renderlo sicuro
- le **vulnerabilità scoperte** di **recente non vengono immediatamente corrette** da Microsoft e da
data la natura frammentata di Windows, molti sistemi rimangono senza patch.

## Tipi di Vulenrabilità windows

- **Divulgazione di informazion**i - Vulnerabilità che consente ad un utente malintenzionato di accedere a dati riservati.
- **Buffer overflow** -  si verifica quando ad un programma si fornisce un surplus di dati rispetto alla sua effettiva capacità di memoria.
- **Remote code execution** - consente a un utente  di eseguire codice in modalità remota
- **Privilege escalation**- consente a un utente malintenzionato di elevare il proprio livello di privilegi dopo la compromissione iniziale.
- **Denial of Service (DOS)** - consente a un utente malintenzionato di consumare le risorse di un sistema/ospite (CPU, RAM, rete, ecc.) impedendo di conseguenza il funzionamento del sistema.
