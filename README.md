### Cosa sono le applicazioni web?

- Le applicazioni Web sono programmi **software** che vengono **eseguiti** **su server Web** e sono **accessibili** su Internet **tramite** **browser** Web.
- Sono progettati per fornire **funzionalità** **interattive** e **dinamiche** **agli utenti**, consentendo loro di svolgere varie attività, accedere alle informazioni e **interagire** con **i dati online.**
- Esempi di applicazioni web sono:
    - Piattaforme di social media (ad esempio, Facebook, Twitter)
    - Servizi di posta elettronica online (ad esempio, Gmail, Outlook)
    - Siti web di e-commerce (ad esempio, Amazon, eBay)
    - Strumenti di produttività basati sul cloud (ad esempio, Google Workspace,Microsoft Office 365

---

### Come funzionano le applicazioni web

- **Architettura client-server:** Le applicazioni Web seguono il modello client-server, in cui la **logica e** i **dati** dell'applicazione sono **ospitati su un server Web** e gli **utenti** vi **accedono utilizzando** i **browser** Web sui loro dispositivi
- **Interfaccia utente (UI)**: L'interfaccia utente delle applicazioni web è
solitamente presentata attraverso una **combinazione di** **HTML** (Hypertext Markup Language), **CSS** (Cascading Style Sheets) e **JavaScript** per creare interfacce dinamiche e interattive.
- **Stateless**: **HTTP**, il protocollo utilizzato per la comunicazione tra browser e server, **è stateless.** Le **applicazioni Web devono gestire le sessioni e lo stato degli utenti per ricordarne le interazioni e garantirne la continuità**

---

### Sicurezza delle applicazioni web

- **CIA**:  L'obiettivo principale della sicurezza delle applicazioni web è garantire la **riservatezza**, **l'integrità** e la **disponibilità dei dati** elaborati dalle applicazioni web, riducendo al contempo il rischio di accessi non autorizzati, violazioni dei dati e interruzioni del servizio.

---

### Pratiche di sicurezza per Web App

- **Autenticazione e autorizzazione:** Implementazione di solidi meccanismi di autenticazione per verificare l'identità degli utenti e controlli di autorizzazione per concedere privilegi di accesso appropriati in base ai ruoli degli utenti.
- **Convalida degli input:** Garantire che tutti i dati immessi dagli utenti siano convalidati per **prevenire** attacchi comuni come **SQL injection e cross-site scripting (XSS).**
- **Comunicazione sicura:** Utilizzo di **protocolli** di **crittografia** come **HTTPS (TLS/SSL)** per proteggere la comunicazione tra il browser dell'utente e il server web, proteggendo i dati sensibili in transito.
- **Pratiche di codifica sicura**: Aderire a standard e pratiche di codifica sicuri per ridurre al minimo l'introduzione di vulnerabilità durante la
fase di sviluppo.
- **Aggiornamenti regolari della sicurezza**
- **Principio del minimo privilegio**: Assegnare i privilegi minimi necessari a utenti, processi e sistemi per ridurre l'impatto potenziale di una violazione della sicurezza.
- **Web Application Firewall (WAF):** Implementazione di un WAF per filtrare e monitorare le richieste HTTP, bloccando il traffico dannoso e proteggendo dai modelli di attacco noti.
- **Gestione delle sessioni:** Implementazione di una gestione sicura della sessione per **prevenire** il **dirottamento** della **sessione** e garantire che l'identità dell'utente sia mantenuta in modo sicuro per tutta la durata della sessione.
