Dopo aver **identificato** una potenziale **vulnerabilità**, il passo logico successivo prevede la **ricerca** del **codice** di **exploit** che può essere utilizzato per **sfruttare la vulnerabilità.**

Il **codice** di exploit può essere facilmente **reperito** **online**, tuttavia è importante notare che scaricare ed eseguire il codice di exploit contro un obiettivo può essere **molto pericoloso**. Si consiglia pertanto di **analizzare** attentamente il **codice** di **exploit** per assicurarsi che funzioni come previsto.
