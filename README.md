Armitage offre le seguenti funzionalità:

- Visualizza i target
- Automatizzare la scansione delle porte
- Automatizzare lo sfruttamento
- Automatizzare lo sfruttamento dei post

Per funzionare correttamente, Armitage richiede che il database di Metasploit
Framework e i servizi di backend di Metasploit siano abilitati e funzionanti.

---

1. `service postgresql start & msfconsole -q`
2. `armitage` **in un’altra CLI**
    1. **connect**
        1. **yes**
